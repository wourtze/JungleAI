### ✨ Что такое JungleAi 

Локальный ИИ-ассистент, который работает прямо на твоём компьютере. Без интернета, без серверов, без лишних глаз.

- **Живое общение** — не шаблонные ответы, а настоящий диалог с характером
- **Память** — помнит о чём говорили, может вспомнить через days
- **Поиск в Википедии** — спроси "что такое X" и получи ответ
- **Автономность** — модель скачивается сама при первом запуске
- **Один клик** — запустил run.bat и всё готово

### 🚀 Установка

1. Установи [Python 3.12+](https://www.python.org/downloads/)
2. Запусти `run.bat`
3. Всё остальное произойдёт автоматически
